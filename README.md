# PythonProject1

A collection of Python programs and practice exercises covering fundamental to intermediate Python concepts.

This repository is created for learning and practicing Python programming concepts through small, focused programs.

## Topics Covered

### 1. Python Basics

* Variables and data types
* Operators
* Conditional statements
* `if`, `elif`, `else`
* Nested `if`
* `for` loops
* `while` loops
* Nested loops

### 2. Functions

* Creating and calling functions
* Function parameters
* Default arguments
* Multiple arguments
* Return values
* Multiple value return
* Recursive functions
* Functions with lists
* Call by value and call by reference concepts

### 3. Lists and Tuples

* Creating and displaying lists
* Adding and removing elements
* Searching elements
* Finding maximum and minimum
* Reversing lists
* Removing duplicates
* Counting occurrences
* Tuple operations

### 4. Number Programs

* Prime number
* Armstrong number
* Palindrome
* Fibonacci series
* Factorial
* Reverse number
* Automorphic number
* Power calculation
* Square-related programs

### 5. Object-Oriented Programming

The repository contains examples of major Python OOP concepts:

* Classes and objects
* Constructors
* Instance variables
* Static variables
* Getter and setter
* Encapsulation
* Inheritance
* Multilevel inheritance
* Multiple inheritance
* Hierarchical inheritance
* Hybrid inheritance
* Method overriding
* Polymorphism
* Operator overloading
* Inner classes

### 6. Interfaces and Abstraction

* Abstract classes
* Abstract methods
* Interface concepts
* Informal interfaces
* Multiple interface examples

### 7. Decorators and Generators

* Function decorators
* Decorator with arguments
* Generator functions
* Fibonacci generator
* Generator with loops
* File-based generators

### 8. Exception Handling

Examples covering:

* `try`
* `except`
* Multiple `except` blocks
* `ValueError`
* `ZeroDivisionError`
* `TypeError`
* `raise`
* `finally`

Example:

```python
try:
    x = int(input("enter x:"))
    y = int(input("enter y:"))
    print(x / y)
except ValueError:
    print("invalid integer")
except ZeroDivisionError:
    print("division by zero")
except TypeError:
    print("invalid type")
```

### 9. File Handling

The repository includes programs for practicing file handling and working with text files.

### 10. Modules and Packages

Examples demonstrate:

* Creating modules
* Importing modules
* Creating packages
* Using packages
* Working with built-in modules
